# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately through [GitHub Security Advisories](https://github.com/ma-kahar/dona-bridge/security/advisories/new).

We will respond within 72 hours and work with you on a fix and coordinated disclosure.

## Scope

- Secrets leaking outside Windows Credential Manager
- MCP server authentication bypass
- XSS or code injection in the shell webview
- WhatsApp webview capability escalation (wa-remote getting shell-level access)
- App Lock bypass

## Out of Scope

- WhatsApp web.whatsapp.com itself — report those to Meta
- Issues requiring physical access to an unlocked machine
